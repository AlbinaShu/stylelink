# Frozen review-level folds

Канонический артефакт для review-level benchmark — `review_group_folds_v1_1.csv`. Его описание и контрольные суммы находятся в `manifest.json`.

- 1 200 отзывов и 40 `item_group_id` назначены ровно одному из пяти folds.
- Размеры validation-folds: 254, 238, 230, 241 и 237 отзывов.
- В downstream-экспериментах назначения читаются из CSV и не вычисляются заново.
- Файлы `review_group_folds_v1.*` в этом каталоге superseded: они сохранены только для provenance и не используются в новых экспериментах.

Новая генерация допустима только как новый версионированный артефакт; `v1_1` не перезаписывается.
