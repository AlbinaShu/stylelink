# Методологические решения

## Принятые решения текущего этапа

| Проблема | Решение | Как отражать в выводах |
|---|---|---|
| Связанные отзывы одного товара создают leakage | Использовать пять frozen folds по `item_group_id` | Все review-level модели сравнивать только на этих folds |
| `no_signal` смешивается с направлением посадки | Разделить Signal F1, Direction Macro-F1 и 4-class Macro-F1 | Основная метрика выбора — Direction Macro-F1 |
| Строгие правила v4 меняют результат гибридного пайплайна | Не смешивать независимую B2 с постправилами в основном сравнении | Гибрид показывать только как отдельную диагностику |
| Трёхклассовая информативность предсказывается слабо | Свести её к `high` против `not_high` | Вес `2/1` считать простой exploratory-гипотезой |
| Спорные review-level метки | Использовать подтверждённый исследователем adjudication | Считать их Gold текущего проекта и раскрыть происхождение |
| Всего 40 товарных групп | Не усложнять CV и не добавлять ручную разметку на текущем этапе | Не делать строгих item-level выводов |
| Confidence может быть плохо откалиброван | Заморозить единый порог `0.60` по validation | Показывать качество вместе с Coverage |
| Внешний набор мал и размечен одним человеком | Использовать его только после заморозки модели | Называть проверкой переноса, не репрезентативным benchmark всего Маркета |
| Нет item-level Gold | Выполнить только exploratory pilot | Не объявлять победителя equal-weight/weighted |

## Итог основного сравнения

B2 TF-IDF + Logistic Regression выбрана среди B0, B1, B2, frozen ruBERT и frozen DistilRuBERT: Direction Macro-F1 `0.754`. Transformer-варианты использовали frozen CLS-признаки; full fine-tuning не проводился.

После выбора модель и порог `0.60` заморожены, затем без перенастройки применены к 300 отзывам Яндекс Маркета. Внешний Direction Macro-F1 равен `0.756`, Signal F1 — `0.837`.

## Граница допустимого вывода

Исследование подтверждает, что на текущем review-level корпусе B2 превосходит выбранные baseline и frozen-transformer конфигурации и переносится на ограниченный Yandex audit без заметного падения основных метрик.

Исследование не подтверждает, что informativeness-weighted aggregation точнее equal-weight, и не оценивает персональную рекомендацию размера. Для первого нужен независимый item-level Gold, для второго — пользовательские параметры и размерная сетка.
