# Отправка писем опроса

Код добавляет Date и Message-ID и использует TLS с начала соединения для SMTP 465
или STARTTLS для 587. Это не заменяет настройку домена и репутации отправителя.

Перед production-рассылкой:
1. Использовать подтвержденного отправителя у SMTP-провайдера.
2. Для собственного домена настроить SPF с разрешенным SMTP-сервисом, DKIM
   провайдера и DMARC с согласованием домена From. Конкретные DNS-значения
   брать у выбранного провайдера, не копировать из чужого домена.
3. Для отправителя gmail.com использовать разрешенный Gmail SMTP с этим адресом
   From; не пытаться настроить DNS домена gmail.com или подменять From.
4. В SURVEY_FRONTEND_URL указать рабочую прямую HTTPS-ссылку; localhost подходит
   только для локального теста. Не использовать сокращатели ссылок.
5. Проверить письма на Gmail, Mail.ru и Яндексе и их исходные заголовки.
   Зафиксировать SPF/DKIM/DMARC и расположение письма.
6. Отправлять только ожидаемый опрос и одно напоминание. После ответа отправки
   прекращаются. Не смешивать письмо опроса с рекламой и вложениями.

Подтвержденный адрес получателя не гарантирует доставку следующего письма.
sent_at означает успешную SMTP-отправку, не доставку и не прочтение.
Доставка во входящие не гарантируется даже при корректной аутентификации.
[Требования Gmail к отправителям](https://support.google.com/mail/answer/81126)
